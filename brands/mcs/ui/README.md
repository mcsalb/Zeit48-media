# MCS Produkt-Look – nur echte Bilder
Jeder MCS-Post zeigt etwas Echtes von den Produkten. Nachgebaute Mockups werden NICHT verwendet (ui.html bleibt nur als Archiv).
Echte Bilder liegen in `brands/mcs/assets/`:
- `screen-*.png|webp|jpg` – echte Screenshots (MCS Flow, MCS Portal/Archiv, Rechnungsprüfung, Ablauf-Editor, MCS Lager-App)
- `foto-*.png|webp|jpg` – echte Fotos (Lager mit Smartphone/Scanner, Team, Support, beim Kunden)
Einbindung: `"bild":"../mcs/assets/<datei>"` in Bild, Karussell-Folie oder Reel-Szene.
Quelle: Bilder von mcs-alb.de (images/screens, images/mcs-flow, images/fotos) – von Ralf ins Repo geladen, weil die Cloud-Umgebung mcs-alb.de nicht direkt abrufen kann.
